# Roadmap / 路线图

> 仓库内摘录版（中英双语）——完整版见产品文档《产品路线图》，发版时人工同步。

## Now · v0.9.8 Installation Experience & Market Guidance

- Post-install guide card and GUI adaptation entry for plugins (one card across all three sources: what you installed, how to start using it)
- One-click scene bundles (starter bundles for coding and video production — fine-tune the checklist and install in one go)
- Background pre-fetch of market data at startup (no blank page on a slow network)
- Plugin recommendations driven by the task at hand — in the conversation, above the input box, and in the market
- Unified “+” reference menu and slash command panel; context compaction without an arbitrary time limit
- Session search that keeps up with long conversations: only matching messages are shown with hits highlighted; double-click a result to open the full conversation
- Task sessions behave like regular sessions (unread dots clear on open; opening and scroll position follow the same rules)
- Fix batch from hands-on testing (final state of retried commands, concurrent installs, first-run detection state, …)

## Next

- Release feedback fix round and packaged-build verification
- Scene bundle catalogue expansion pending review (office / education / data / content)
- “Configuration” content assets (a one-click demo of connecting Codex to domestic API providers)

## Later

- Declarative panels and agent-generated adaptation templates (deeper GUI adaptation)
- macOS support (Windows first)
- Growing the plugin ecosystem together (SkillHub and the extension ecosystem communities)

# 路线图（中文）

## 进行中 · v0.9.8 安装体验与市场引导

- 插件装后引导卡与 GUI 适配入口（三源统一：装了什么、怎么开始用，一卡看全）
- 场景套装一键安装（编程、视频制作两个起步套装，勾选微调一次装齐）
- 插件市场数据启动即后台预拉取（弱网首开不空白）
- 按任务推荐插件——会话内、输入框上方、市场里三处触达
- + 号引用菜单与斜杠命令面板统一；上下文压缩不再受固定时限约束
- 会话搜索适配长对话：只显示命中的消息并高亮，双击结果即可进入完整会话
- 任务会话与普通会话行为一致（未读绿点点开即清；打开与滚动位置走同一套规则）
- 体验实测修复批（命令重试的最终呈现、并发安装、首启检测状态等）

## 近期

- 收版反馈修复轮与装包活体验证
- 场景套装清单扩列待审定（办公 / 教育 / 数据 / 内容）
- 「配置引流」内容素材（codex 接国产 API 的一键配置演示）

## 远期

- 声明式面板与 agent 自动生成适配模板（GUI 适配深化版）
- macOS 支持（Windows 先行）
- 插件生态共建（SkillHub / 扩展生态双源社区）
