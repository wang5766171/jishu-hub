## 二、后端改动

### 文件
- `src-tauri/src/task_launch.rs`（重写）
- `src-tauri/src/lib.rs`（命令注册）

### 关键改动
1. **存储迁移**：JSON 文件 → 独立 SQLite（`.jishu-hub/tasks/task-instances.db`，WAL 模式，schema version 1）
2. **TaskLaunchInstance 字段扩充**：
   - 新增 `planner_agent_id`（默认 "jishu_agent"）
   - 新增 `active_run_id` / `last_run_id` / `run_status`（执行实例关联）
3. **status / run_status 职责分离**（对应设计 §2.2）：
   - `status` 收敛为 4 值：requirements_discussing / requirements_finalized / planning_discussing / graph_created（终态）
   - `run_status` 独立 5 值：running / paused / completed / failed / cancelled
   - 状态机止步 graph_created，执行态由 run_status 追踪
   - cancelled 流转补全（running/paused → cancelled）
4. **normalize_phase 统一 canonical 为 "execution"**（消除 "graph" 别名）
5. **finalize_requirement 接口简化**：改为 `RequirementFinalizeRequest` 单一入参（`requirement_markdown` + `creation_mode`），终稿格式交给调用方（skill 约束），不再硬编码 render_requirement_markdown
6. **新增命令**：
   - `task_launch_sync_run_status`（前端轮询 run 状态后回写）
   - `task_launch_get_instance`（查单个任务实例）
   - `task_launch_create_from_existing_graph`（孤儿 graph 补建 TaskInstance）

## 三、前端改动

### 新增模块

#### `src/features/chat-core/`（共享会话核心层）
- `types.ts`：PreparedMessage / PendingChatInteraction / UseChatSessionOptions / ChatSessionState 等接口
- `use-chat-session.ts`：通用会话 hook（零任务语义耦合，阶段差异通过声明式入参表达）
  - 复用 streamStore 单例 + useSessionStream 订阅
  - 暴露 messages / stream / send / stop / respondInteraction / resolveApproval / refreshMessages
  - 消费 agent-event 事件（interaction_request / approval_request / session_resolved）
  - **红线遵守**：hook 内部不出现 task/phase/requirement/node 字样

#### `src/features/task-instance/`（任务三阶段容器层）
- `types.ts`：TaskInstance / TaskPhase / TaskInstanceStatus(4) / TaskRunStatus(5) / ExecutionChatScope / ExecutionView + Raw→Instance 转换 + PhaseDisplayState 派生
- `use-task-instance.ts`：任务实例状态管理（列表/活跃任务/阶段/回溯只读/执行视图/节点会话）
- `use-run-event-stream.ts`：执行阶段主任务会话（轮询 task_event 投影为消息流，始终活跃）
- `use-node-session.ts`：节点子代理会话查询（orchestrator_get_attempt → session_id，按需挂载）
- `task-phase-container.tsx`：三阶段容器（React.lazy 入口）
- `task-phase-nav-bar.tsx`：三阶段导航（done/active/pending + 回溯只读）
- `phase-conversation-shell.tsx`：需求/规划阶段共享会话骨架（复用 ChatInput+MessageView+StreamingMessage）
- `phase-requirements-view.tsx`：需求讨论（注入 `<jishu-task-requirements-stage>` 隐藏指令 + 嵌入定稿卡）
- `phase-planning-view.tsx`：流程规划（注入 `<jishu-task-planning-stage>` + 嵌入生成卡）
- `phase-execution-view.tsx`：执行阶段三维模型（展现形式×会话范围×主进程）
  - 主任务会话（useRunEventStream 始终活跃）+ 节点子代理会话（useChatSession 按需挂载）
  - GraphEditor 画布 + ExecutionChatScopeTabs（主任务/各节点切换）+ NodeInspector
  - 切换 chatScope/节点不打断后端执行
- `execution-view-switcher.tsx` / `execution-chat-scope-tabs.tsx`：展现形式与会话范围切换器
- `requirement-finalize-card.tsx` / `graph-generation-card.tsx`：嵌入会话流的确认卡片

### chat-page 集成
- 新增 `taskModeActive` / `taskContainerTaskId` / `taskContainerPhase` 状态
- `React.lazy + Suspense` 动态加载 TaskPhaseContainer（独立 chunk）
- 侧边栏执行阶段任务条目点击 → 打开 TaskPhaseContainer（替代旧 TaskWorkbench）
- 规划生成图后 → 打开 TaskPhaseContainer 落在执行阶段
- **渐进式迁移**：与现有 taskLaunchOpen/taskPanelOpen 共存，不破坏现有功能
