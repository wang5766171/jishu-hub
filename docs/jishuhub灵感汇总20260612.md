- 会话中的 markdown，**三个点（折叠）渲染增加复制**（06-02）
- 搜索会话列表，**显示会话最近的时间**（06-03）

- 关闭时**增加任务运行提示**（06-02）
- **自动识别不相关任务**，提示开启新对话（06-10）

- **自动执行提示**：自动执行禁止列表外的命令；点击配置可跳转设置页面；生成自动禁止列表（参考百度 comate）（06-10）
- **一键启动命令**（06-06）

- **AI 员工**概念（06-03）
- **skill os**（06-08）

### 4. 知识 / 记忆 / 图谱
- **对话内容进行图谱**（05-28）

- **生成记忆片段**（06-06）

- jishu-hub 如何**实现"责任"的记录**（06-11）
- 支持参考开源系统，**抓取可参考的内容形成记忆**（06-12）

### 5. 配置与环境检测
- **环境检测**，智能体需提示有一个即可（06-04）
- 项目配置，**权限出现两个默认**（06-04，bug）
- 配置保存**没有保存成功的提示**；provider 配置中应支持**选择供应商自动带出对应地址**（06-01）
- 支持**用户将当前配置更新到模板**（06-09）
- **无限 token 模式 / 节省 token 模式**（06-11）
- **显示 token 用量**（06-04）
- jishu TUI 现在能进去，但需要做适配：**模型未读取 jishu-hub 上配置的，页面还显示 pi**（06-11，bug）

### 6. 界面与交互优化
- 悬浮窗口显示**项目名称**，格式类似 `项目名称 | 会话名称`，设计好看点（06-01）
- 点击链接没有关闭链接的窗口，可**做成点击链接就跳转浏览器**（06-05）
- **消息插队功能**：输入消息后停止框变发送，删除消息后变停止（06-03）

### 7. Git 集成
- 能直接**点击 git 提交记录，查看这次提交的文件**（06-02）
- **git 提交直接定位到会话**（06-09）

### 8. 兼容性 / Bug
- **claude 对中文目录项目支持问题**（06-01）
- 项目切换后，存在**输出流断开**的问题（06-01）
- claude 的 plan 模式需要和用户对齐，但**在 jishuhub 中未显示需要反馈的内容**（plan 模式返回的 questions/options 未在 UI 渲染）（06-02）
- **hook 没有识别到**（06-02）
- 打开软件点击置顶智能体切换按钮，**疯狂弹黑窗口一闪即逝**（05-29，bug）
- **一点击停止就把整个消息清空**了（06-02，bug）
