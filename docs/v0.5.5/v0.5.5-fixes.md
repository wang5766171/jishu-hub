# v0.5.5 修复报告

基于 v0.5.4 审查报告，筛选高重要性、低功能风险的 11 个问题进行修复。

---

## 修复清单

### 安全类

#### 1. 文件读取路径校验（H2）
- **涉及文件**: `src-tauri/src/lib.rs`、`src-tauri/src/image.rs`
- **修复内容**: `read_text_file`、`read_file_as_base64`、`read_image_as_data_url` 三个命令添加路径校验，拒绝访问用户主目录之外的文件
- **影响范围**: 仅影响文件读取操作，对已有功能无影响；会拒绝不合法的路径请求

#### 2. save_session_files label 清洗（H3）
- **涉及文件**: `src-tauri/src/image.rs`
- **修复内容**: 新增 `sanitize_label` 函数，将 label 中的 `/`、`\`、`\0` 替换为 `_`，`..` 替换为 `_`，防止路径穿越写入
- **影响范围**: 仅影响文件名生成，不影响已有文件

#### 3. PowerShell 特殊字符转义（H5）
- **涉及文件**: `src-tauri/src/hub.rs`
- **修复内容**: `find_process_by_resume` 中对 marker 字符串的 `[`、`]`、`*`、`?` 添加 PowerShell 反引号转义
- **影响范围**: 仅影响进程查找的过滤表达式构建，不影响正常使用

### 稳定性类

#### 4. 原子文件写入（M4）
- **涉及文件**: `src-tauri/src/config.rs`、`src-tauri/src/hub.rs`
- **修复内容**:
  - `config.rs`: `save_config`、`restore_backup`、`import_config` 改为先写 `.tmp` 文件再 `rename`，防止崩溃时文件被截断
  - `hub.rs`: 新增 `atomic_write` 函数，`write_json` 使用原子写入
- **影响范围**: 文件写入行为对上层透明，内容不变

#### 5. 备份文件自动清理（M5）
- **涉及文件**: `src-tauri/src/config.rs`
- **修复内容**: 新增 `cleanup_old_backups` 函数，每次创建备份后自动清理旧文件，仅保留最近 10 个
- **影响范围**: 减少磁盘占用，不影响配置管理功能

### 内存/资源类

#### 6. 图片缓存 LRU 淘汰（M7）
- **涉及文件**: `src/components/sessions/inline-image.tsx`
- **修复内容**: 新增 `evictCache` 函数，当缓存条目超过 50 个时自动淘汰最早的条目
- **影响范围**: 长时间使用后内存更稳定；被淘汰的图片在需要时会重新加载

### 前端健壮性

#### 7. commands-page 定时器清理（M10）
- **涉及文件**: `src/pages/commands-page.tsx`
- **修复内容**: 组件卸载时 `clearTimeout`；重复点击时先清理旧定时器再设新定时器
- **影响范围**: 修复组件卸载后的 React 警告，不影响功能

#### 8. CopyButton 定时器清理（L6）
- **涉及文件**: `src/components/sessions/message-view.tsx`
- **修复内容**: 使用 `useRef` 存储 timeout ID，组件卸载时清理
- **影响范围**: 修复潜在内存泄漏和 React 警告

#### 9. 移除调试 console.log（L7）
- **涉及文件**: `src/components/projects/add-project-dialog.tsx`
- **修复内容**: 移除 `handleBrowse` 中的两处 `console.log` 调试语句
- **影响范围**: 无功能影响
