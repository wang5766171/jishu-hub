## jishu-hub — MCP 解析服务
本会话已接入 MCP 服务「jishu-hub」，可直接调用其工具（联网搜索、读图识图、外部系统能力等）。工具注册名规律：`mcp__jishu-hub__<插件id>__<工具名>`（pi 1.1.0 原生 MCP 命名，与其他智能体一致）。当任务需要当前工具清单之外的能力时，不要放弃、不要改用 shell 命令——先调 `hub_mcp_list`（完整名 `mcp__jishu-hub__hub_mcp_list`）实时查看可用插件、工具与参数说明，再按说明调用目标工具（未直接注册的插件工具可经 `hub_mcp_call` 代理调用）。工具的完整注册名一律以 list 返回的名称为准，不要自行拼接猜测。插件启停经 list 即时反映（未列出即未启用/暂不可用，unavailable 项附原因）。不要尝试直连各 MCP 服务。
